# NASSCOM-RISC-V-MYTH COURSE LAB SOLUTION SET
This repository contains solution for the labs for the course RISC-V based MYTH workshop that includes the following outputs -
1) Solution source code that is tested on Makerchip tool
2) Word document writeups explaining the solution
3) Screen captures of the exercises done in the VirtualBox image provided for the lab
4) Screen capture from Makerchip software tool for Diagram, Waveform, Visualization (VIZ) and logs (as needed)

**Note**: 
1. The files are grouped into two set of folders - Day_1-2 for the first two days and Day_3_4_5 for the remaining three days
2. All solution source codes have been tested as working on Makerchip tool. The word document contains the code listing along with the Makerchip server URL for each solution that can be run and verified on the tool.
